# VELORA - Luxury E-Commerce Website

A premium luxury fashion and lifestyle e-commerce website built with React.js and Vite.

## Features

- Product Collections
- Shopping Cart
- Wishlist
- Product Search
- Filtering and Sorting
- Product Details
- Checkout
- Dark/Light Mode
- Fully Responsive Design

## Technologies

- React.js
- Vite
- JavaScript
- CSS3
- React Router
- Context API
- LocalStorage
